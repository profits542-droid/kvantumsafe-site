KvantumSafe TLS & Perimeter Scanner API

A public read-only method that opens a real TCP/TLS connection to port 443 and returns the certificate details as JSON. The scanner is built on the patented KvantumSafe Pro Framework SDK core (Kyrgyz Republic Certificate No. 1259 dated Nov 9, 2026).

KvantumSafe TLS & Perimeter Scanner API

Публичный метод только для чтения: открывает настоящее TCP/TLS-подключение к порту 443 и возвращает данные сертификата в JSON. Сканер разработан на базе запатентованного ядра KvantumSafe Pro Framework SDK (Свидетельство КР № 1259 от 09.11.2026 г.).

GET

{{if eq .Lang "en"}}Method address{{else}}Адрес метода{{end}}

GET https://kvantumsafe.tech/scanner/api/scan

{{if eq .Lang "en"}}Host: https://kvantumsafe.tech. Query parameters are added after the path.{{else}}Хост: https://kvantumsafe.tech. Параметры запроса добавляются после пути.{{end}}

{{if eq .Lang "en"}}Parameters{{else}}Параметры{{end}}

domain

{{if eq .Lang "en"}}Public domain name, for example bakai.kg. Required.{{else}}Публичное имя домена, например bakai.kg. Обязательный.{{end}}

lang

{{if eq .Lang "en"}}ru or en. Chooses the language of the log lines.{{else}}ru или en. Выбирает язык строк в журнале.{{end}}

{{if eq .Lang "en"}}JSON response{{else}}Поля JSON-ответа{{end}}

tls_version

{{if eq .Lang "en"}}Negotiated TLS version, for example TLS 1.3.{{else}}Согласованная версия TLS, например TLS 1.3.{{end}}

cipher_suite

{{if eq .Lang "en"}}Name of the cipher suite chosen for the connection.{{else}}Название набора шифров, выбранного для соединения.{{end}}

ip

{{if eq .Lang "en"}}Resolved address that accepted the connection.{{else}}Адрес, с которым установлено соединение.{{end}}

issuer

{{if eq .Lang "en"}}Issuer of the TLS certificate.{{else}}Издатель TLS-сертификата.{{end}}

not_after

{{if eq .Lang "en"}}Certificate expiry time in UTC (RFC3339). Empty if the handshake did not complete.{{else}}Срок окончания сертификата в UTC (RFC3339). Пусто, если рукопожатие не завершилось.{{end}}

logs

{{if eq .Lang "en"}}Step-by-step lines of the DNS, TCP, and TLS check.{{else}}Пошаговые строки проверки DNS, TCP и TLS.{{end}}

{{if eq .Lang "en"}}The response also includes domain, subject, not_before, ok, and error. An unknown domain returns HTTP 400.{{else}}В ответе также есть domain, subject, not_before, ok и error. Неизвестный домен возвращает HTTP 400.{{end}}
